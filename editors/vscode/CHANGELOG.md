# Change Log

All notable changes to the "vietlang" extension will be documented in this file.

## [0.1.0] - 2026-08-21
- Initial release of VietLang language support for Visual Studio Code.
- Added comprehensive TextMate syntax grammar for VietLang keywords, types, strings, operators, and docstrings.
- Added 20+ backend snippets for HTTP servers, database drivers, JWT auth, and WebSocket broadcasting.
- Added bracket matching and auto-closing configuration.
